# NASA Data Sources

AstroQuest is designed to integrate official NASA planetary information.

Planned sources:
1. NASA Planetary Data System (PDS): https://pds.nasa.gov/
2. NASA Open Data Portal: https://data.nasa.gov/
3. NASA APIs: https://api.nasa.gov/

Prototype note: The current simulation uses local sample values so it can work offline. Actual NASA datasets should be selected, cited and validated before scientific values are presented as mission parameters.
